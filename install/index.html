How to set it up: just set two environment variables — OPEN_ENGLISH_DATABASE_URL (the first target, typically aruaru-db) and OPEN_ENGLISH_DATABASE_URL_SECONDARY (the second, typically a standard PostgreSQL).     チェックを入れる = その言語をインストール(追加)、チェックを外す = アンインストール(削除)です。 インストールした言語だけが「学びたい言語」メニュー・資格対策コーナーの模擬試験メニュー・多言語の連続読み上げに現れます。 インストール・アンインストールはいつでも何度でも行え、メンテナンスや自動アップデートの後もその状態が保たれます。
    Checking a box installs (adds) that language; unchecking it uninstalls (removes) it. Only installed languages appear in the "Learn" menu, the practice-exam menu, and the multilingual read-aloud. You can install or uninstall at any time, as often as you like, and your choices are kept across maintenance and automatic updates.

    Honest disclosure: the multilingual quizzes are original practice questions written for this app. They are not past questions from, and are not affiliated with or endorsed by, any official language certification exam (DELE, DELF, Goethe-Zertifikat, HSK, TOPIK, etc.). Levels are loose CEFR-style approximations only, and the number of questions per language is uneven (currently 3–6 items per language) — the count is shown next to each language.
    正直な開示: 多言語クイズは本アプリ用に書き下ろしたオリジナル練習問題です。実在の語学資格試験 (DELE・DELF・Goethe-Zertifikat・HSK・TOPIK等)の過去問ではなく、それらとは一切無関係で、公認も受けていません。 レベル表記はCEFR風の大まかな目安に過ぎず、収録問題数も言語ごとに不均一(現状3〜6問)です——各言語の横に実際の問題数を表示しています。

    母国語・言語の組み合わせ・表示順の設定は、メンテナンスや自動アップデートを挟んでも保持されます(ブラウザのlocalStorage + ローカルSQLite DBの二重保存。localStorageが消えてもDB側から復元します)。
    Your native language, language selection, and display order are kept across maintenance and automatic updates (stored both in the browser's localStorage and in the local SQLite database; if localStorage is cleared, the settings are restored from the database).

    🔊 多言語で連続表示・読み上げ / Sequential multilingual display & read-aloud

    選択した言語(英語・日本語を含めて最低2か国語・最大5か国語)の順に、同じ内容を画面へ表示しながら音声で読み上げます。 英語・日本語は常に有効なので、追加できるのは最大3言語までです。
    The same content is shown and read aloud in each selected language, in order (minimum 2, maximum 5 languages including English and Japanese; since those two are always on, you can add up to 3 more).

    ↕ 表示・読み上げの順番 / Display & read-aloud order

    順番は3つの方法で指定でき、どれを操作しても互いに連動します: ①数字を直接入力(1〜6)、 ②1(左)〜6(右)のラジオボタン、③▲▼ボタン。 既に他の言語が使っている番号を指定した場合は、その言語と順番を入れ替えます(同じ番号が重複することはありません)。 母国語には🏠が付きます。並び順も保存され、次回以降も同じ順番で表示・読み上げされます。
    You can set the order in three interlinked ways: (1) type the number (1–6), (2) pick a radio button from 1 (left) to 6 (right), or (3) use ▲ / ▼. Choosing a number already used by another language swaps the two, so numbers never collide. Your native language is marked with 🏠, and the order is saved for next time.

    Honest disclosure: read-aloud uses the browser's built-in Web Speech API. If your browser/OS has no installed voice for a language, that line is displayed but may be read with a wrong-language voice or skipped silently — this app does not bundle its own speech engine. The phrase translations are best-effort and may sound stiff to native speakers.
    正直な開示: 読み上げはブラウザ内蔵のWeb Speech APIを使います。その言語の音声がOS/ブラウザに入っていない場合、 文章は表示されますが別言語の声で読まれたり無音でスキップされたりします(本アプリは独自の音声合成エンジンを同梱していません)。 フレーズの訳文は最善努力ベースで、母語話者には硬く聞こえる場合があります。
