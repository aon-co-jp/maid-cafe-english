open-english via Facebook / Facebook経由

Why this page exists / このページについて

Some mobile plans in certain countries only allow access to the internet through Facebook (so-called zero-rating programs such as "Free Basics"). This page is meant to be opened as a link shared on a Facebook Page, in a Facebook post, or from a Messenger conversation, so that people on such a plan can still reach it from inside the Facebook app's built-in browser.
一部の国のスマートフォン契約では、Facebook経由(「Free Basics」等の ゼロレーティングプログラム)以外のインターネットアクセスができない 場合があります。このページはFacebookページの投稿やMessengerの 会話で共有されたリンクとして開かれることを想定しており、Facebook アプリ内蔵ブラウザからでも到達できるようにしたものです。

Honest disclosure / 正直な開示

We cannot make open-english load for free under an actual Facebook "Free Basics" zero-rating plan — that requires an official partnership/whitelisting agreement with Meta that this project does not have, and no app can add itself to that allow-list unilaterally. What this page can do honestly is work as a normal link that opens fine inside Facebook's own in-app browser (tapping a link in a Facebook Page post or a Messenger chat) — on a Facebook-only zero-rating plan, this page itself may still count as free to load if it is reached from inside Facebook, but any files you download from the links below (installers) will use your normal data allowance, since Meta does not zero-rate file downloads to third-party sites.
実際のFacebook「Free Basics」ゼロレーティングプランの元で open-englishを無料アクセス対象にすることはできません——それには Meta社との公式な提携・ホワイトリスト登録が必要で、本プロジェクト 側だけで一方的に登録することはできないためです。このページが 正直にできることは、Facebookページの投稿やMessengerのチャット内の リンクとして、Facebookアプリ内蔵ブラウザから開けるようにすることの みです。Facebook限定プランの場合、Facebook経由でこのページ自体を 開く通信は無料になる可能性がありますが、下記リンクからの インストーラーのダウンロード自体は通常のデータ通信量を消費します (Metaは第三者サイトへのファイルダウンロードをゼロレーティング 対象にしないためです)。

What happens after you download / ダウンロード後の流れ

open-english is still the same self-hosted app described in the main README: you download an installer, install it on your own phone/tablet/PC, and it runs its own local server on your device (server/, this repository) plus the AI engine (aruaru-llm). Facebook is only the entry point for reaching this page and the download links — the app itself does not run inside Facebook.
open-englishは変わらず、メインのREADMEで 説明している自己ホスト型アプリです。インストーラーをダウンロード してご自身のスマホ/タブレット/PCへインストールすると、端末上で 自前のローカルサーバー(このリポジトリのserver/)と AIエンジン(aruaru-llm) が起動します。Facebookはこのページとダウンロードリンクへの 入口としてのみ機能し、アプリ本体がFacebook内で動作するわけでは ありません。
