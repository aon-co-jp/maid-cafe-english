This page itself cannot force a browser or mode switch, but if Chrome is installed ahead of time, a dedicated desktop shortcut can be created that always opens a fresh Chrome Incognito window when double-clicked (using Chrome's real, documented --incognito launch option — not a workaround). Creation script: launchers/windows/create-vault-incognito-shortcut.ps1 (run it in PowerShell to create the desktop icon). The shortcut opens the main app's (index.html) top page, not vault.html standalone — vault.html only works correctly when embedded as an iframe in the parent page (GitHub push / Google Search delegation talk to the parent via postMessage), so opening it standalone would break those features (key encryption/storage/decryption alone still works). If your local address differs from the default (127.0.0.1:4601), pass -ServerHost/-ServerPort.
The same applies if you open an incognito/private window yourself instead of using the script above — paste in the open-english app's own URL (production: https://easy-web.tokyo/open-english/, local: e.g. http://127.0.0.1:4601/), not this vault.html page's own URL. Once it's open, load this vault.html's URL as an iframe from within one of the app's panels (Drawing Ops, the freelance corner, etc.).
