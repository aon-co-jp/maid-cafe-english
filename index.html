    For extra safety: a dual aruaru-db + PostgreSQL setup — now implemented. Running both and keeping one as a copy of the other means a failure on one side does not lose your learning history. Implementation status (updated 2026-08-24): open-english now writes to two databases at once itself — the earlier note on this page saying this was "not implemented yet" no longer applies. How to set it up: just set two environment variables — OPEN_ENGLISH_DATABASE_URL (the first target, typically aruaru-db) and OPEN_ENGLISH_DATABASE_URL_SECONDARY (the second, typically a standard PostgreSQL). It does not matter which one you assign to which, since both are treated as ordinary PostgreSQL connections. Set both and every record is written to both; set one and only that one is used; set neither and it falls back to the built-in SQLite as before. The two writes are fully independent: if one database is down or unreachable, the write to the other still completes and your session is never interrupted — only the failing side is noted in the server log.
